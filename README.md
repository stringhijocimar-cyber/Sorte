# SpeakFlow AI

Aplicativo multiplataforma para prática de inglês falado com IA, desenhado para unir diagnóstico, conversação, feedback e revisão em um único fluxo de aprendizagem.

## Fundação atual

- Expo + React Native + TypeScript
- Expo Router
- Onboarding guiado
- Diagnóstico inicial simplificado
- Home com rotina diária
- Biblioteca inicial de cenários reais
- Sessão de conversação com serviço de IA desacoplado (mock na primeira fundação)
- Feedback pós-sessão
- Modelo de domínio para CEFR, competências, erros e progresso

## Rodar localmente

```bash
npm install
npm start
```

## Regra de produto

Um módulo só é considerado pronto quando funciona ponta a ponta: entrada do usuário, regra de negócio, persistência/integração necessária e retorno perceptível ao usuário.

## Próximas integrações

1. Persistência local e conta do usuário.
2. Motor real de conversação por IA.
3. Speech-to-text e text-to-speech.
4. Diagnóstico adaptativo completo.
5. Revisão espaçada e histórico.
6. Analytics de progresso.
